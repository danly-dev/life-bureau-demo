# 本版素材来源

本版图片从项目 `art_library` 复制，页面与节点由 HTML/CSS 动态构建。
原审核页名称和编号不因游戏实现而改变。

- bureau / entry / studio：A01、A02、A03。
- cover / poster：A05、A06；poster采用第二轮修正姿态的版本。
- female / male / grandma：B01、B02、B03。
- zhixia：B04第二轮；aunt：B05年龄调整版；friend / colleague：B06、B07。
- film / photo / clip / camera / stamp：C01—C05。
- paper / boxes / row / col / burst / color / brush / hint：D01—D08。
- clue / back：E01、E02。
- icons / logo：F01、F07。

人物全身／头像、箱子和导航图标由CSS从审核组件表中显示对应区域，源图片未做破坏性编辑。
动态数值、关卡号、按钮文案不使用审核图内烘焙的文字。

旧版遗留的 `complete-photo.png` 等文件可能仍在本目录，但新代码不引用它们；不再使用旧版双婴儿结局。
